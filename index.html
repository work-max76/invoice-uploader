請求書アップロード支援ツール

【請求書発行月(YYMM)】_【拠点名】_【取引先名】_【金額(税込)】.pdf の名前で、選択したPDFを共有フォルダへそのまま保存（アップロード）できます。対応ブラウザは Google Chrome / Microsoft Edge です。

お使いのブラウザは共有フォルダへの自動保存に対応していません。Google Chrome または Microsoft Edge で開いてください。それ以外のブラウザでは「名前を変えてダウンロード」機能のみご利用いただけます。

1. 共有フォルダの設定（初回のみ）

共有フォルダが未設定です。下のボタンから、会社の共有クラウドがPC上で見えているフォルダ（請求書の保存先ルートフォルダ）を選択してください。

選択したフォルダの中に「年月／拠点名」のサブフォルダを自動作成し、その中に保存します（例：選択フォルダ ＞ 2026年7月 ＞ 本社 ＞ ファイル）。フォルダは請求書発行月と選んだ拠点名から自動判定されます。次回以降は選択したルートフォルダが自動で読み込まれます。フォルダのパス自体はブラウザの仕様上表示されません。

2. 情報を入力してPDFを選択

拠点名リストは全員共通で自動配信されます（このページの管理者がGitHub上のファイルを更新すると反映されます）。
スキャンまたはダウンロードした請求書PDFを選択してください。

文字情報を持つPDF（WEB発行のPDF等）はある程度読み取れますが、紙をスキャンした画像PDFは読み取れません。自動入力された値は必ず目視で確認・修正してください。

取引先名リストを編集する（よく使う取引先を登録）

登録すると、取引先名欄への入力時に候補として表示されます（クリックで選択も、新しい取引先の自由入力も可能です）。表記ゆれ防止のため、正式名称で登録してください。

3. ファイル名の確認とアップロード

請求書発行月・拠点名・取引先名・金額・PDFを入力してください
